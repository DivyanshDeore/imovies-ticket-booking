# IMovies — Deployment Details

## Project Information

- Project Name: IMovies — Online Movie Ticket Booking System
- Description: An online movie ticket booking application.
- Frontend: React.js, TypeScript
- Backend: Node.js
- Database: MongoDB Atlas

## Live Deployment

**Deployment URL:** https://imovies-ticket-booking.onrender.com/

## GitHub Repository

https://github.com/DivyanshDeore/imovies-ticket-booking

## Database

The application uses MongoDB Atlas for cloud database management.

Database credentials and connection strings are stored in environment variables and must not be exposed publicly.
